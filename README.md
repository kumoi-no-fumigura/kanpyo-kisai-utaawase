## 作品について

春・夏・秋・冬・恋の各二十番からなる大規模な歌合。判詞はなく、紀友則・紀貫之・藤原興風らの歌が古今集に多く採られた。

## 底本

- [新校 群書類従 第八巻](https://dl.ndl.go.jp/pid/1879743)（内外書籍株式会社 編・群書類従・内外書籍・1928年・p249-253）

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館の全文テキスト（OCR）から作品の範囲を切り出し、原本のページごとに段落に分け、ページの先頭や末尾にある書名（柱）を除きました。それ以外は手を加えていません。旧字の誤認識・ルビ・割注などがそのまま混じっています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |

段落ID（例: `kanpyo-kisai-utaawase-0001`）は、本文を直しても変わりません。原本の画像は、底本のリンクからコマ番号で見られます。
